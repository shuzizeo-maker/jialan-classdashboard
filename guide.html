1. 先看這裡：不用安裝任何程式

📘 想看有圖、可以打勾記進度的完整教學，請到 儀表板零基礎教學網（儀表板最下面一排的 📘 教學網 也能打開）。

班級儀表板是一個網頁，只要用瀏覽器打開網址就能用，不需要安裝軟體，也不需要管理員權限。

2. 第一次使用（約 5 分鐘）

  1. 在教室要投影的那台電腦打開 Edge 或 Chrome，輸入上面的網址（或點本頁上方的「開啟班級儀表板」）。
  2. 先選身分：導師（一個班） 或 科任老師（多個班）。科任老師請看下方說明；導師接著會出現設定視窗，依序確認：
    • 學校名稱（已預填，可修改）
    • 班級名稱：改成您的班級，例如「三年甲班」
    • 學年度（只填數字，例如 115）與學期
    • 最大座號：點選人數按鈕或直接輸入
    • 空號：有轉出的座號才填，例如 7、15，沒有就空白
  3. 設定教師密碼（至少 4 碼，輸入兩次）。這個密碼用來進入「教師控制台」，請記下來。
  4. 按 開始使用，完成！
  5. 建議接著進入 🔒 教師控制台 → 座號與名單 輸入學生姓名（可從 Excel 整欄複製貼上；不想顯示姓名也可以空白，只用座號）。
科任老師（教好幾個班）：選「科任老師（多個班）」後，每一列填一個班（班級名稱例如「六甲」、科目例如「自然」、最大座號、空號），按「＋ 再加一班」可以繼續加。設定完成後，首頁班級名稱下方會出現 ⇄ 換班級，點一下就能切換；每一班的名單、金幣、作業、聯絡簿、每日任務和公告都分開。到「教師控制台 → 週課表」在每一格下方選「這節是哪一班」，上課時間到就會自動換班（可在「班級管理」關閉）。

3. 放到桌面，以後一鍵開啟

方法 A：Edge 安裝成「應用程式」（推薦）

  1. 用 Edge 開啟班級儀表板。
  2. 點右上角 ⋯ → 應用程式 → 將此網站安裝為應用程式。
  3. 名稱可改成「班級儀表板」，按 安裝。
  4. 之後桌面與開始功能表會出現圖示，點兩下就會以獨立視窗開啟，沒有網址列，畫面更大。

方法 B：Chrome 建立捷徑

  1. 用 Chrome 開啟班級儀表板。
  2. 點右上角 ⋮ → 投放、儲存及分享 → 建立捷徑…。
  3. 勾選 以視窗開啟，按 建立。

方法 C：最簡單

把瀏覽器網址列左邊的 🔒 圖示直接拖曳到桌面，就會產生一個捷徑。

💡 想要開機就自動出現？Edge：設定 → 開始、首頁和新索引標籤 → 「Microsoft Edge 啟動時」選「開啟這些頁面」→ 新增儀表板網址。

🌿 金幣與山林圖鑑（班級經營）

  • 每完成一項任務 +1 金幣；老師也可以在控制台加減金幣。
  • 每位學生每累積 10 金幣，就會在山林裡「發現」一種新物種（鳥類、動物、昆蟲、植物共 40 種，以嘉蘭在地物種為主）。
  • 全班金幣累積 100，「班級山林」升一級，背景會長出更多樹，大家發現的物種也會出現在背景裡。
  • 📒 金幣存摺（v1.13.0）：底部 全班夥伴 → 點學生，看「💰 餘額」「📈 累計獲得」「🎁 已兌換」和每一筆金幣紀錄，不需要密碼。可按 📋 複製紀錄 或 ⬇️ 下載 CSV。
  • 🎁 兌換獎品（v1.13.0）：在金幣存摺按 🎁 兌換獎品（要教師密碼），從獎品清單點選或直接輸入名稱和金幣。金幣不夠不能兌換；兌換錯了按 撤銷 退回金幣（紀錄會保留並標上「已撤銷」）。兌換不會讓物種進度和班級山林倒退。

5. 教師控制台

點底部 🔒 教師控制台，輸入密碼。解鎖後按鈕會變成黃色的 🔓 已解鎖 X 分。

📅 填寫週課表（三種方法）

教師控制台 → 週課表。填好後，首頁作息表會依今天星期幾顯示「第一節 國語」，左上的 📅 整週課表 可以看整週。

  1. 直接輸入：在格子裡打科目，或從下拉選單挑（國語、數學、族語、學扶…）。
  2. 從 Excel／校務系統貼上：選取整張課表（含左邊節次欄）→ 複製 → 展開「從 Excel 或校務系統貼上」→ 貼上 → 按 填入格子。標題列和早自修、午休列會自動略過。
  3. 用課表照片：展開「用課表照片產生」→ 按 複製 AI 指令 → 打開 Claude、ChatGPT 或 Gemini，上傳課表照片並貼上指令 → 把 AI 回覆的文字貼回「從 Excel 貼上」的框框 → 填入格子。AI 偶爾會看錯字，請核對後再儲存。
每一節的上下課時間在 作息時間 分頁設定，預設已有第一～九節。如果課表某一節顯示「未設定時間」，請到作息時間補上。

🎌 國定假日與本校自訂

教師控制台 → 🎌 假日。國定假日已經內建（行政院人事行政總處公布的 2026、2027 年辦公日曆），2028 年以後會在連上網路時自動下載。

  • 設定：要不要顯示國定假日、公告提前幾天提醒（1／3／7 天，預設 3 天）、要不要提醒補班、要不要自動從網路下載。改好按 儲存設定。
  • 本校自訂：按 ＋ 新增本校放假／補課，選日期（一段日期就填結束日期）、類型（🎌 放假／📚 上課（補課））、名稱（例如歲時祭儀、颱風假、校慶補假）。補課要選「這天上哪一天的課」。本校自訂優先於國定假日，所有班級共用、包含在備份裡，開始新學年會保留。
  • 放假的平日不排課，科任老師的自動換班也會跳過；補課日照選的那一天課表上課。

🛡️ 防止學生亂改

  • 公告、班級資料、加扣金幣一定要密碼才能修改。
  • 聯絡簿、倒數日預設也要老師解鎖才能新增或刪除（上鎖時會顯示「🔒 老師解鎖後才能新增」）。若想讓小老師自己登記，可在「基本資料」勾選「允許不輸入密碼就新增／刪除聯絡簿、倒數日」。
  • 解鎖後只要 5 分鐘沒有操作就會自動上鎖；離開座位前也可以到「資料管理」按 登出教師模式 立即上鎖。重新整理頁面也會上鎖。
  • 任務打卡不用密碼，方便學生自己點座號；點錯的打卡學生可以自己取消，老師也可以在「加扣金幣」調整。

加扣金幣／兌換上方切換：➕ 加扣分 選座號（可多選、全選）→ 按 +1、+5、−1 等，可填原因，會永久記在學生的金幣存摺；🎁 兌換 點一位學生再選獎品或直接輸入，下方有這一班的兌換紀錄和「撤銷」；🏷️ 獎品清單 設定常用獎品和金幣（所有班級共用）
🧩 應用中心新增常用教學網站（圖示、名稱、https 網址、說明、分類、在儀表板裡打開或用新分頁打開）；編輯、刪除（會再確認）、↑↓ 排順序、📌 釘選（最多 3 個）、▶ 試開。所有班級共用，包含在備份裡，開始新學年保留（v1.14.0）
📜 更新紀錄每一版新增、修改、移除、修正了什麼（v1.13.0）。更新後第一次打開會自動跳出「🆕 這次更新了什麼」；點畫面下方的版本號也能看
資料管理手動備份（下載檔案或複製備份內容）、還原（選檔案或貼上內容）、自動備份（資料夾或這個瀏覽器裡）、變更密碼、開始新學年、完全重設

6. 天氣設定（選用）

預設使用免費的 Open-Meteo 天氣資料，不用設定就能顯示金峰鄉天氣。

若想改用中央氣象署的鄉鎮預報：

  1. 到 opendata.cwa.gov.tw 免費註冊會員並登入。
  2. 點「取得授權碼」，複製那串 CWA- 開頭的文字。
  3. 儀表板 → 教師控制台 → 基本資料 → 天氣「資料來源」選 中央氣象署開放資料，貼上授權碼。
  4. 其他鄉鎮的學校：把「鄉鎮名稱」改成自己的鄉鎮；不是臺東縣的話，「資料集」也要換成該縣市的鄉鎮預報代碼。
  5. 按 儲存。天氣卡最下面顯示「資料來源：中央氣象署」就成功了。
授權碼是您個人的，請不要分享給別人；每位老師可以各自申請。

7. ⚠️ 資料保存與備份（很重要）

所有資料（名單、金幣、圖鑑、聯絡簿…）都存在這台電腦的這個瀏覽器裡。以下情況資料會消失或看不到：

❌ 電腦有「還原卡」或「還原系統」（重開機就回到原狀）：每次關機資料都會被清掉！請洽資訊組將瀏覽器資料排除還原，或每天下課前匯出備份。
❌ 清除瀏覽紀錄時勾了「Cookie 和其他網站資料」
❌ 使用 InPrivate／無痕視窗（關閉視窗就消失）
❌ 換一台電腦或換另一個瀏覽器（資料不會跟過去，需要用備份檔匯入）

怎麼備份

  1. 教師控制台 → 資料管理 → ⬇️ 手動備份（下載檔案）。
  2. 會下載一個 班級儀表板_班級_手動備份_日期.json 檔案，存到隨身碟或雲端硬碟。
  3. 如果儀表板嵌在 Google 協作平台裡、檔案沒有下載下來：按 📋 複製備份內容，打開記事本貼上，存成 .json 檔。
  4. 建議每週備份一次，期末與換學年前一定要備份。

自動備份

  • 資料管理 → 勾 啟用自動備份，選每日或每週、時間。
  • 直接打開網址（Chrome、Edge）時，可以存到 📁 電腦裡的資料夾，或 🗂️ 這個瀏覽器裡。
  • 嵌在 Google 協作平台裡（或用 Firefox、Safari）時，不能選資料夾，會自動存在這個瀏覽器裡，不用開新分頁。最近 14 份會列在「存在這個瀏覽器裡的備份」，可以按 ⬇️ 下載 或 還原。
「存在這個瀏覽器裡的備份」可以救回改錯、刪錯的資料，但清除瀏覽器資料、換電腦或換瀏覽器時會一起不見。所以還是要偶爾手動備份，把檔案存到隨身碟或雲端硬碟。
為什麼嵌在協作平台時不用開新分頁？因為瀏覽器會把「嵌在協作平台裡的儀表板」和「直接打開的儀表板」的資料分開存，開新分頁去備份，備份到的會是另一份資料。

怎麼還原／搬到新電腦

  1. 在新電腦打開儀表板網址，先隨便完成第一次設定（密碼之後會被備份檔裡的密碼取代）。
  2. 教師控制台 → 資料管理 → ⬆️ 還原備份檔 → 選擇 json 檔 → 還原。選不了檔案時，可以按 📋 貼上備份內容還原，把備份檔的內容貼進去。
同一台電腦有多位老師使用？同一個瀏覽器只能存一位老師的資料（科任老師自己的多個班級可以放在一起）。請每位老師各用一個瀏覽器「設定檔」（Edge 右上角頭像 → 新增設定檔），或一位用 Edge、一位用 Chrome。

8. 換學年／換班級

  1. 教師控制台 → 資料管理 → 開始新學年。
  2. 系統會先自動備份一份（下載一份，也在這個瀏覽器裡留一份），再清空學生金幣、圖鑑、打卡紀錄、聯絡簿、點名紀錄與名單。
  3. 保留：學校名稱、作息表、每日任務、倒數日、密碼、🧩 應用中心。科任老師會清空每一班的學生資料，班級清單與週課表保留，再到「班級管理」調整班級。
  4. 接著到「基本資料」改新的班級名稱、學年度、學期，到「座號與名單」改人數與姓名。

9. 沒有網路時（離線版）

如果教室網路不穩，也可以把整個儀表板下載到電腦裡：

  1. 到專案的 GitHub 頁面，點綠色 Code → Download ZIP。
  2. 在下載的 ZIP 上按右鍵 → 解壓縮全部，放到「文件」或桌面。
  3. 打開資料夾，在 index.html 上按右鍵 → 開啟方式 → Edge 或 Chrome。
  4. 可在 index.html 上按右鍵 → 傳送到 → 桌面（建立捷徑）。
離線版沒有網路時不會顯示天氣，其他功能都可以用。注意：離線版和網址版的資料是分開的，要搬資料請用「手動備份」再「還原備份檔」。

10. 常見問題

忘記教師密碼怎麼辦？

密碼只存在這台電腦，無法查詢。若有備份檔，可清除這個網站的資料後重新設定，再匯入備份（備份檔中的密碼會一起還原，請先確認記得備份當時的密碼）。若都沒有，只能重新開始。

按了計時器卻沒有聲音？

請確認電腦喇叭沒有靜音。瀏覽器規定要先在頁面上點一下才能播放聲音，按「開始」就算點過了。

音量偵測沒有反應？

網址列左側的圖示 → 網站權限 → 麥克風設為「允許」，再重新整理頁面。

天氣一直顯示「無法取得」？

通常是網路暫時中斷，系統會每 5 分鐘自動重試，並保留最後一次成功的資料。若使用氣象署，請確認授權碼正確。

中間的分頁（例如「倒數」）變灰色、點不到？

舊版在螢幕比較矮（投影機、嵌在協作平台、瀏覽器放大）時，分頁裡的內容會往上蓋住分頁列。v1.12.1 已修正：請按 Ctrl + Shift + R 重新整理，確認左下角版本是 v1.12.1 以上。內容放不下時，可以在分頁裡上下捲動。

應用中心的網站在儀表板裡打不開？

有些網站（例如 Google 的服務、許多登入頁面）不允許被放在別的網頁裡，畫面會空白或顯示「拒絕連線」。請按上方的 ↗ 用新分頁打開；常常這樣的話，到「教師控制台 → 🧩 應用中心」按 ✏️ 編輯，把開啟方式改成「用新分頁打開」。另外網址一定要 https:// 開頭。

原住民族歲時祭儀、颱風假沒有出現在假日裡？

國定假日只有全國一起放的假。歲時祭儀（各族日期不同）、颱風假、校慶補假、學校的補課日，請到教師控制台 → 🎌 假日 →「本校自訂」自己加；加好後作息表、課表和公告都會跟著變。

學校行事曆的「顯示天數」打不進數字？

v1.20.0 的天數框是白底白字，其實有打進去只是看不到。v1.20.1 已修正：請按 Ctrl + Shift + R 重新整理。打好天數（1～30）按 Enter 或點別的地方就會套用。

學校行事曆的 GAS 程式碼框是空白的？

v1.20.1 以前程式碼框是白底白字，其實有程式碼只是看不到。v1.20.2 已改成深色底、亮色字：請按 Ctrl + Shift + R 重新整理，打開「📖 GAS 程式碼與 3 分鐘設定步驟」就能捲動閱讀；部署時一樣按 📋 複製 GAS 程式碼。

畫面太小或太擠？

按 F11 全螢幕；或按 Ctrl + -／+ 縮放，Ctrl + 0 恢復。

我是別的學校，可以用嗎？

可以！第一次設定時把學校名稱改掉即可；天氣地點在教師控制台 → 基本資料修改（Open-Meteo 填學校的緯度、經度）。

學生的資料安全嗎？

資料不會上傳到任何伺服器，只存在本機瀏覽器。教師密碼是為了防止學生誤改，並非高強度保護，建議不要輸入身分證字號、電話等敏感個資，姓名也可以只填暱稱或不填。

# 班級儀表板（山林版）

臺東縣金峰鄉嘉蘭國小 六年甲班 的教室投影用班級儀表板。純網頁（HTML + CSS + JS），不需要伺服器，可直接放上 GitHub Pages。

## 功能
- **全螢幕**：直接開啟可用系統全螢幕；嵌在 Google Sites 時改為「新分頁全螢幕」或「放大模式」（iframe 常無 allowfullscreen）。注意跨站 iframe 的 localStorage 可能被瀏覽器分區，與新分頁資料不一定相同。
- **首頁**：跑馬燈公告（可自動顯示「尚未訂正」等任務未完成座號）、學校／班級名稱、作息表（自動標示現在節次與剩餘時間）、聯絡簿、倒數日、天氣（Open-Meteo，預設金峰鄉）
- **工具**：大時鐘、倒數計時（🏝️ 3D 島嶼畫面，可改 🎡 彩色轉盤或簡潔）、番茄鐘、任務完成進度、抽號（可不重複，五種動畫每次隨機）、教室音量偵測（人聲帶過濾，減輕咳嗽／掉筆／拖桌椅誤判）、環境音（溪流、微風、細雨、鳥鳴、蟲鳴，瀏覽器即時合成）
- **一週作業**：一次排週一～週五作業（可複製到下一天／套用到每天），儲存後寫入各日聯絡簿，隔天即可檢查
- **主題色**：櫻花粉紫、極光藍、螢光橘、流光綠、星空夜、晨曦金與原始山林，右上角 🎨 切換
- **作業檢查**：聯絡簿項目自動變成待檢查作業（今天佈置、明天開始查）；先選上方狀態（預設 ✓ 完成），再點座號，點錯再點一次改回沒交（v1.12.0 起）；可補登舊作業；跑馬燈自動列出未繳／待訂正（含跨天累積）
- **每日任務**：打掃、放學整理等固定打卡，每項 +1 金幣（與作業檢查分開）
- **金幣存摺與兌換（v1.13.0 起）**：全班夥伴點學生看「餘額／累計獲得／已兌換」與每一筆金幣紀錄（不需密碼，可複製或下載 CSV）；「🎁 兌換獎品」與「撤銷」需教師密碼，可用共用的獎品清單或直接輸入；金幣不夠不能兌換；兌換不會讓物種進度和班級山林倒退
- **🧩 應用中心（v1.14.0 起）**：最下面一排「🧩 應用」打開常用教學網站（不需密碼），可分類、搜尋；教師控制台 → 🧩 應用中心 新增／編輯／刪除／排序／試開；可在儀表板裡全畫面打開或用新分頁打開；最多釘選 3 個到最下面一排；監考是第一個內建應用；所有班級共用、包含在備份裡
- **🎌 國定假日（v1.16.0 起）**：內建人事行政總處 2026、2027 年放假日（2028 年起連上網路自動下載）；作息表、整週課表、一週作業、日期都會標出假日，放假的平日不排課；跑馬燈提前 1／3／7 天提醒放假、連假合成一句、提醒補班；教師控制台 → 🎌 假日 可加本校自訂的放假（歲時祭儀、颱風假…）或補課日，所有班級共用、包含在備份裡
- **嘉蘭內建應用（v1.15.0 起）**：應用中心預設有 🏝️ 嘉蘭樂學島（Google 協作平台禁止嵌入，用新分頁）、🧰 嘉蘭工具箱（在儀表板裡打開）、📘 儀表板教學網（新分頁），不釘選，可編輯、刪除（刪掉不會再出現）
- **更新說明（v1.13.0 起）**：更新後第一次打開會跳出「🆕 這次更新了什麼」；點畫面下方版本號或「教師控制台 → 📜 更新紀錄」可再看
- **全班夥伴／山林圖鑑**：每累積 10 金幣發現一種新物種；圖鑑共 40 種（鳥類、動物、昆蟲、植物各 10 種），以嘉蘭在地物種為主
- **班級山林**：全班金幣累積到 100 升一級，背景長出更多樹，已發現的物種會出現在山林背景中
- **班級統計**：近 7 天完成率、各座號金幣
- **教師控制台**（密碼保護）：基本資料、座號與名單（可從 Excel 貼上）、作息表、每日任務、加扣金幣／兌換／獎品清單、匯出／匯入備份、📜 更新紀錄、變更密碼、新學年重設

## 使用方式
- 本機測試：在此資料夾執行 `python -m http.server 8765`，開啟 http://localhost:8765
- 第一次開啟會出現設定畫面：先選身分（導師一個班／科任老師多個班），再確認校名、班級、座號，並設定教師密碼。
- 點名（v1.9.0 起）：首頁班級名稱下方或底部「🙋 點名」（需教師密碼），標記病假、事假、公假、曠課、遲到。首頁顯示「今日缺席 N 人：03 號（病假）…」或「今日全到 🎉」，跑馬燈自動加上今日缺席（可關閉）。預設只顯示座號。抽號、每日任務會跳過今天缺席的同學。每班分開記錄，保留約一學期，含在備份裡。
- 3D 島嶼倒數、抽號動畫（v1.11.0 起）：「倒數」分頁顯示會轉動的山林小島和彩色倒數膠囊（最後 10 秒變紅、時間到動物跳起來）；抽號有五種動畫（🎰 拉霸機、🎡 幸運轉盤、🥚 扭蛋機、🃏 翻牌、🐾 班寵抽號），預設每次隨機，可按「⏭ 跳過動畫」。都在「教師控制台 → 基本資料 → 🎬 動畫效果」切換（倒數可改「簡潔」，抽號可「關閉動畫」），平板卡卡時建議改簡潔／關閉。
- 🎡 彩色轉盤倒數（v1.17.0 起）：教師控制台 → 基本資料 → 🎬 動畫效果 →「倒數計時的畫面」選「🎡 彩色轉盤」。一圈 20 格彩虹色塊會依經過的時間從上面順時針一格一格變暗，計時中外圈小燈泡跑馬燈，中間是知心，時間到知心跳起來＋鈴聲。中間的角色可以換成老師自己的圖片（縮小後存在這台電腦瀏覽器的 IndexedDB，不在備份檔裡），也可以恢復知心
- 監考模式（v1.10.0 起）：底部「📝 監考」全畫面打開監考看板（不需密碼），「✕ 回到儀表板」需再確認；開啟時暫停環境音／音樂與動畫，關閉後恢復。網址與是否顯示按鈕在「教師控制台 → 基本資料 → 📝 監考看板」或「🧩 應用中心」設定（https 限定，所有班級共用）。v1.14.0 起監考是應用中心的第一個內建應用。
- 我的音樂（右側環境音區塊）：「📁 上傳檔案」「📂 加入資料夾」「🔗 加入網址」。Chrome／Edge 直接開網址時只記住檔案位置；嵌在 Google Sites、Firefox、Safari 時會複製一份存在瀏覽器裡（IndexedDB），重新整理後也能播，不需要開新分頁（v1.9.1 起）。換電腦或清除瀏覽器資料時要重新加入。
- 科任老師（v1.8.0 起）：可加入多個班級，首頁上方「⇄ 換班級」切換；在週課表標記每一節是哪一班，上課時間到會自動換班。班級可在「教師控制台 → 班級管理」新增、改名、排序、刪除。

## 重要：資料存放
資料存在「這台電腦這個瀏覽器」的 localStorage。換電腦、換瀏覽器、清除瀏覽資料前，請先到「教師控制台 → 資料管理 → ⬇️ 手動備份（下載檔案）」。嵌在 Google Sites 時下載若被擋，可用「📋 複製備份內容」貼到記事本存檔；還原可選檔案或「📋 貼上備份內容還原」。
自動備份（v1.9.0 起）：能選資料夾時（Chrome／Edge 直接開網址）存到資料夾或瀏覽器裡；嵌在 Google Sites、Firefox、Safari 時自動存在瀏覽器裡（IndexedDB，保留最近 14 份，可下載或還原），不需要開新分頁。
**嵌在 Google Sites 時注意（重要）：** 現代 Chrome／Safari 會對「跨站 iframe」做 **storage partitioning（儲存分區）**，iframe 裡的 localStorage 可能跟「直接打開 GitHub Pages 網址／新分頁」不是同一份。建議上課以「↗ 新分頁全螢幕」或直接開 Pages 網址為主；兩邊資料若不一致，用匯出／匯入備份同步。
教師密碼只是防止學生誤改，不是高強度資安保護；請勿在此存放敏感個資。

## 換學年
教師控制台 → 資料管理 → 「開始新學年」：自動備份（下載一份，並在瀏覽器裡留一份）後清空學生資料與點名紀錄，再設定新班級名稱與座號。科任模式會清空每一班的學生資料，班級清單與週課表保留。

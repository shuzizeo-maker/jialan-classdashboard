# 班級儀表板（山林版）

臺東縣金峰鄉嘉蘭國小 六年甲班 的教室投影用班級儀表板。純網頁（HTML + CSS + JS），不需要伺服器，可直接放上 GitHub Pages。

## 功能
- **首頁**：跑馬燈公告、學校／班級名稱、作息表（自動標示現在節次與剩餘時間）、聯絡簿、倒數日、天氣（Open-Meteo，預設金峰鄉）
- **工具**：大時鐘、倒數計時、番茄鐘、任務完成進度、抽號（可不重複）、教室音量偵測、環境音（溪流、微風、細雨、鳥鳴、蟲鳴，瀏覽器即時合成）
- **任務打卡**：學生點座號打卡，每項 +1 金幣
- **全班夥伴／山林圖鑑**：每累積 10 金幣發現一種新物種；圖鑑共 40 種（鳥類、動物、昆蟲、植物各 10 種），以嘉蘭在地物種為主
- **班級山林**：全班金幣累積到 100 升一級，背景長出更多樹，已發現的物種會出現在山林背景中
- **班級統計**：近 7 天完成率、各座號金幣
- **教師控制台**（密碼保護）：基本資料、座號與名單（可從 Excel 貼上）、作息表、每日任務、加扣金幣、匯出／匯入備份、變更密碼、新學年重設

## 給同事
不用安裝，打開網址即可使用。完整的安裝、桌面捷徑、備份與常見問題請看 **[使用說明 guide.html](guide.html)**（儀表板右下角「❓說明」也能開啟）。

## 維護者：更新網站
修改檔案後執行：
```bash
git add .
git commit -m "說明這次改了什麼"
git push
```
約 1～2 分鐘後 GitHub Pages 網址會自動更新；同事重新整理頁面就是新版，資料不受影響。

## 使用方式
- 本機測試：在此資料夾執行 `python -m http.server 8765`，開啟 http://localhost:8765
- 第一次開啟會出現設定畫面：確認校名、班級、座號，並設定教師密碼。

## 重要：資料存放
資料存在「這台電腦這個瀏覽器」的 localStorage。換電腦、換瀏覽器、清除瀏覽資料前，請先到「教師控制台 → 資料管理 → 匯出備份檔」。
教師密碼只是防止學生誤改，不是高強度資安保護；請勿在此存放敏感個資。

## 換學年
教師控制台 → 資料管理 → 「開始新學年」：自動下載備份後清空學生資料，再設定新班級名稱與座號。
